Drop your images into this folder with these exact filenames:

  mom.jpg          <- the BIG center photo of just Mom
  photo1.jpg       <- left column, top
  photo2.jpg       <- left column
  photo3.jpg       <- left column (middle)
  photo4.jpg       <- left column
  photo5.jpg       <- left column, bottom
  photo6.jpg       <- right column, top
  photo7.jpg       <- right column
  photo8.jpg       <- right column (middle)
  photo9.jpg       <- right column
  photo10.jpg      <- right column, bottom

Tips:
- Any file format works (jpg, png, webp) as long as the extension is .jpg
  in the filename — or update the references in index.html to match.
- Side photos are cropped to squares. Center mom.jpg uses a 4:5 portrait crop.
- Any missing photo shows a "📷" placeholder so the layout doesn't break.
