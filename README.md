# Happy Mother's Day 💐

A little scrapbook site made with love.

## How to add your photos

Drop these files into the `images/` folder (exact names matter):

- `background.jpg` – hero background image
- `photo1.jpg` through `photo6.jpg` – family photos

## How to edit the message

Open `index.html`, find the section that starts with `<!-- ✏️ REPLACE THIS WITH YOUR OWN MESSAGE -->`, and write whatever you want to say.

You can also edit the captions under each polaroid (look for `<figcaption>`).

## How to preview locally

Just double-click `index.html` to open it in your browser.
